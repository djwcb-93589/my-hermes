# 示例 Skill

## 何时使用

说明哪些用户请求应触发这个 Skill，以及哪些相似请求不属于它。

## 执行流程

1. 读取完成任务所需的输入。
2. 使用现有公开接口执行操作。
3. 检查输出是否完整，并向用户说明结果和限制。

## 安全边界

- 不扩大工具、路径、网络或审批权限。
- 不把个人数据、凭据或运行时状态写入 Skill。
- 能力不可用时明确说明降级原因，不使用未授权的替代方案。
